Bench suite 0.9.0 · rescanned 28 Aug 2026

A complete agent system, shaped like Unix.

Bench is not a framework, SDK, or hosted platform. It is thirteen programs whose contracts compose through argv, streams, files, signals, processes, and exit status. This map compares the capabilities—not the packaging—with prominent 2026 systems.

How to read it

Do not grade a Unix system by SDK-shaped boxes.

A framework imports a graph, a hosted platform owns a control plane, and Bench composes processes. The right comparison asks whether the system can express, persist, replay, inspect, constrain, and verify the work—and then names the exact unit and boundary of that guarantee.

Adoption note. There is no credible apples-to-apples usage census across model APIs, coding workbenches, RAG libraries, sandboxes, observability platforms, and durable workflow engines. “2026 reference points” below means prominent, widely deployed or ecosystem-visible systems with current primary documentation—not a fabricated rank order.

The composed system

The important capabilities live between programs.

Looking at one executable at a time misses the system Bench forms. These are native Unix compositions already present in 0.9.0.

Event spine + full replay

Two event-sourced replay domains, one evidence path

Ask folds append-only JSONL events back into the exact normalized request at any request sequence. It verifies contiguous events, request digests, inline Context snapshots, provider-replayable reasoning blocks, and sealed program records for checks, approvals, confinement, contracts, and results. Tend independently replays its immutable lifecycle events into the current job projection and verifies that projection plus every digest-bound attempt and check artifact. Trail reads the same Ask events; there is no shadow trace format.

Precise boundary: replay reconstructs and verifies recorded conversation/request state and Tend controller state. It does not re-perform an external effect or prove that a recorded producer told the truth.
Evaluation

A check is an evaluator, and its verdict is evidence

Ply runs an operator-owned check before work and after every candidate, returns rejection evidence to the model, and seals every accepted, rejected, or broken verdict into the replayable session. Draft mutation-tests checks. Bench ships a frozen 60-case routing conformance corpus; Agent ships a lifecycle corpus. Exact replay makes any archived run stable input to later code, model, safety, cost, or regression evaluators.

Not bundled: a hosted experiment catalogue, aggregate statistics, annotation queues, or comparison dashboard.
Memory

Four memories, each with a different authority

Ask provides exact thread memory and attributed compaction lineage. Agent provides curated MEMORY.md and durable file-shaped state. Hone turns only replay-verified fail→pass recoveries into reviewed procedural memory consumed through Brief. Context supplies self-contained retrieved evidence snapshots that replay without refetching, while Trail provides archive recall and lineage.

Not bundled: automatic embedding search, background consolidation, self-editing memory, or an opinionated forgetting policy.
Multi-agent

Agents are processes, specialists are isolated homes

Agent validates nested specialist homes with separate goals, instructions, tools, checks, checkpoints, and evidence. Ply can invoke another Ply as an ordinary tool, propagates model policy, records independent sessions, bounds nesting, and teaches root-controlled fan-out and synthesis. The shell supplies background jobs, wait, xargs -P, pipes, and per-child status artifacts.

Not bundled: a provider-specific handoff object, shared in-memory graph state, or a distributed team scheduler.
Workflow + durability

POSIX is the workflow language; Tend is the durable process boundary

Shell, Make, pipes, conditionals, loops, background jobs, wait, cron, launchd, systemd, and CI already express sequences, branches, fan-out/join, schedules, and retries. Tend adds SQLite transactions, exact argv, serialization keys, immutable events, leases, timers, durable signals, indefinite human waits, cancellation, attempt artifacts, and explicit resolution of uncertain effects—without requiring workflow callbacks.

Not bundled: multi-host queues or automatic checkpointing of arbitrary in-process function calls. Split durable steps into programs/jobs, or add a distributed substrate when that deployment boundary is required.

Hone is not a lesser memory system; it is a stricter procedural one. It requires evidence that the old behavior failed and the new behavior passed, retains provenance, and separates proposal from admission. It omits automatic extraction/retrieval and similarity search by policy, not because Bench lacks durable memory.

trailevent archive query

agentfolder-shaped worker

The OpenAI Agents SDK, Google ADK, and LangGraph subgraphs provide SDK-shaped single- and multi-agent runtimes.
Agent already has first-class multi-agent structure: recursively validated specialist homes have isolated context, authority, checks, checkpoints, and evidence; the shell supplies parallelism and aggregation. It lacks a hosted/distributed scheduler and shared in-memory handoff graph, not multi-agent capability.

tendevent-sourced process durability

Tend is a real durable workflow substrate whose atomic unit is an ordinary process. Temporal/DBOS/Restate automatically journal calls inside application code and operate multi-host services; Tend instead lets POSIX define topology and makes uncertain effects explicit rather than claiming transparent exactly-once behavior.

The conventional build

The rest of the industry assembles a stack.

There is no single mainstream product that matches Bench’s whole boundary. A conventional 2026 implementation usually combines several of the systems below. Each card also names an idea Bench can productively borrow while keeping programs and POSIX at the center.

Agent loop + tool protocol

OpenAI Agents SDK, Google ADK, LangGraph, MCP

Libraries own the loop, tool schemas, handoffs, guardrails, sessions, and callbacks. MCP standardizes the network-facing capability catalogue. Bench distributes those jobs across Ask, Ply, Agent, Brief, ordinary executables, and the standalone mcp/mcpbox edge.

Bench has borrowed: a lossless request filter plus a reviewed namespace compiler for Tools, Resources, Prompts, Tasks, continuations, and subscriptions—without introducing a second internal tool model. Streamable HTTP, safe template expansion, binary unpacking, Registry proposals, and reverse serving remain later slices.
Workflow + durability

LangGraph, Temporal, DBOS, Restate

Graph SDKs persist node state; durable-execution platforms journal calls and distribute work across managed workers. Bench uses shell and Make for topology, Ask for exact request replay, and Tend for transactional, event-sourced process durability.

Bench should borrow: define an optional remote-runner protocol and adapters for multi-host placement; retain exact argv and explicit unknown effects rather than imitating transparent exactly-once claims.
Tracing + evaluation

LangSmith, OpenAI tracing, OpenTelemetry

Hosted systems collect spans, datasets, evaluators, experiment comparisons, metrics, feedback, and alerts. Bench already owns richer authoritative local inputs: full Ask events, sealed Ply receipts, Tend events, checks, mutation tests, and frozen corpora.

Bench should borrow: ship read-only OpenTelemetry and experiment-report projections over existing events—aggregate scores, cost, latency, and regressions without creating a shadow log.
Memory + knowledge

Letta, LangGraph memory, LlamaIndex

Memory runtimes automatically update agent state; RAG systems ingest, index, embed, retrieve, rerank, and synthesize. Bench separates exact thread history, curated memory, verified procedural memory, archive recall, and self-contained Context evidence.

Bench should borrow: publish first-party Context connectors for indexes and rerankers plus optional recall policies; keep automatic consolidation and self-editing behind explicit, reviewable programs.
Multi-agent

CrewAI, Google ADK, LangGraph subgraphs

Frameworks represent collaborators as objects, handoffs, shared graph state, or role declarations. Bench represents them as isolated worker homes and nested processes, using shell fan-out/join and replayable per-child artifacts.

Bench should borrow: improve reusable fan-out, budget, cancellation, and synthesis commands; add a remote scheduler only as a process-placement service, never as hidden shared agent state.
Sandbox + serving

Docker, E2B, Cloudflare, n8n, Dify

Sandboxes provide stronger machine isolation; platforms provide APIs, channels, connectors, autoscaling, dashboards, and visual operations. Cage currently controls writes and network on the host, while external Unix services trigger and supervise Bench.

Bench should borrow: add disposable-machine and secret-broker adapters, plus a thin service wrapper when needed. Do not move goals, checks, event truth, or authority into that wrapper.

What the map says

Bench is complete at the Unix-system boundary.

Replay, evaluation, memory, multi-agent work, workflows, retrieval, authority, and durable execution are already present. The difference is their unit of composition and deployment boundary—not an absence of those capabilities.

Native today

Replay, evals, memory, teams, workflows

Ask and Tend provide two verified replay domains. Checks, sealed verdicts, mutation testing, and frozen corpora provide evaluation. Agent, Ask, Hone, Context, and Trail provide distinct kinds of memory. Nested homes and processes provide teams. POSIX plus Tend provides workflows.

Different by design

The operating system is the framework

Programs are capabilities; PATH is the tool registry; byte streams are the protocol; files are durable objects; exit status is control flow; shell, Make, schedulers, signals, and process groups are orchestration. SQLite is used narrowly where Tend needs transactional coordination.

Precisely outside

Services above one Unix host

No multi-host worker fabric, automatic journal of arbitrary in-process calls, hosted realtime/API plane, managed vector index, semantic citation judge, unified span dashboard, or complete read-and-secret isolation. Those are genuine outer boundaries—not evidence that Bench lacks agents, memory, evaluation, replay, or workflows.

Protocol edge

Use all of MCP by translating it into Unix.

Ply’s contrib/mcpbox proved the central move: tools/list is a directory of programs waiting to happen. The maintained mcp/mcpbox sibling now implements that edge while keeping Ply unaware of MCP: one self-contained request reports an honest terminal, unfinished, or effect-unknown result; staged capability folders project reviewed Tools, Resources, Prompts, Tasks, continuations, and subscriptions into programs, readers, prompt filters, explicit handles, and JSONL streams. Context normalizes selected resources, Tend supervises waits, May remains exact authorization, and Ask remains the event writer. The 2026 protocol’s stateless core and explicit handles fit this architecture unusually well. Read the concrete Unix-native MCP design and the current MCP 2026-07-28 release.
